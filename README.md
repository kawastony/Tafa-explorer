# Tafa Explorer

Public geometric universe observatory by **Tony Kawas (kawastony)**.

Live: **https://kawastony.github.io/Tafa-explorer/**

## Modes

- **Sky** — confirmed exoplanets on a celestial sphere (RA/Dec anchors)
- **Cosmos** — Kawastony-inspired a(t) expansion scrubber with quantumOmega(a) and H(z)
- **Lens** — 35 degree TAFA cone, dual spiral arms, sightline geometry
- **Lab** — live H0 / Omega_q readouts and observatory metrics
