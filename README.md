# Tafa Explorer

Public geometric universe observatory by **Tony Kawas (kawastony)**.

Live: **https://kawastony.github.io/Tafa-explorer/**

## NASA + light-year chronology

Sky targets use distances from the **NASA Exoplanet Archive** (`pscomppars`, `sy_dist`).

For each world the observatory shows:

- Distance in light-years and parsecs
- **Light travel time** (years of light)
- **Light left** epoch (calendar year the photons started toward Earth)

A **light-year chronology** strip orders nearby → distant systems so you can scrub the past by eye.

## Modes

- **Sky** — NASA-linked exoplanets on the celestial sphere + chronology strip
- **Cosmos** — dual readout: scale factor `a(t)` and lookback time (Gyr)
- **Lens** — 35° TAFA cone, dual spiral arms, sightlines
- **Lab** — H0 / Omega_q / lookback metrics
