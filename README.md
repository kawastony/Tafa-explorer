# TAFA Explorer

**Public interactive universe traveling observatory**  
Built on the TAFA (Topological Axion Field Architecture) / Golden Dragon geometric lens  
by Tony Kawas (kawastony).

Live modes:
- **Sky** — NASA-inspired star catalogs & sky navigation
- **Cosmos** — large-scale structure & expansion visualization
- **Lens** — quadratic / cone geometry lens overlays (TAFA core)
- **Lab** — Dual TOE physics sandbox + stress metrics

**New in this public release: Classical Score player**  
Ambient classical music + generative cosmic score that can be toggled while exploring.  
The private `universe-explorer` prototype did not include music; this version does.

This repo is ready for GitHub Pages.

**https://kawastony.github.io/Tafa-explorer/**

## Features
- Real-time Three.js scene with stars, nodes, connections, orbital rings
- Dual TOE physics inspiration (Consciousness-First + Quantum-First)
- Interactive node selection, heatmap, speed control
- **Classical Score player** (play / pause / next + volume)
- Exportable node data
- Clean dark UI tuned for long exploration sessions
